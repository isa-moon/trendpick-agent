# HTML 版选题方案：固定样式

每次交付 Markdown 的同时，生成一份 HTML，方便直接发给客户或在浏览器里看。

## 怎么生成

```bash
python3 scripts/render_html.py <台账目录>/<品牌>-<YYYY-MM-DD>-选题.md
```

输出在 Markdown 旁边，同名 `.html`。把两个文件的路径都告诉用户。

## 硬规则：不要自己写 HTML

- **只用 `render_html.py` 生成**。不要手写 HTML、不要另写 CSS、不要改 `assets/report.css`、不要在 Markdown 里夹 HTML 标签
- 样式是固定的：换模型、换电脑、换 Agent，出来都是同一个样子。你能影响的只有 Markdown 内容，所以 Markdown 必须按 `card-format.md` 的格式写
- 脚本报错或没有 Python 时，只交付 Markdown，并告诉用户 HTML 没生成及原因，不要用别的方法拼一个

## Markdown 怎么写，HTML 才好看

脚本按固定字段识别结构，下面这些写对了，对应的样式才会出来：

| Markdown 写法 | HTML 里变成 |
|---|---|
| 第一个 `# 标题` | 封面大标题 |
| 开头的 `- **结论**：追 N 条｜等 M 条｜跳过 K 条，其中红线 X 条` | 封面三张数字卡：追（绿）、等（琥珀）、跳过（灰） |
| 开头的 `**品牌自身**`、`**大环境**`、`**数据**` | 封面下方的信息栏 |
| `## 推荐…`、`## 观察（等）`、`## 建议跳过`、`## 我替你拍的板`、`## 数据说明` | 白底章节卡，左侧色条区分类型，顶部导航自动生成 |
| `### 【追】标题` 或 `## 1.【追】标题` | 绿色左边框的选题卡 |
| 卡内 `**一句话**：` | 卡片顶部的浅绿结论条 |
| 卡内 `**五维**：` 下面 `- 维度：强｜依据` | 五维表：强（绿）、中（琥珀）、弱（橙）、冲突（红） |
| 卡内 `**切入角度**：` 下面 `1. 角度名：说明。钩子：…。露出：…。风险：…` | 带序号的角度卡，钩子、露出、风险分行 |
| 跳过表的「类型」列：`时机 + 黄线`、`红线` | 彩色标签：红线红、黄线和时机琥珀、调性紫、饱和蓝、竞品和 IP 橙 |
| `## 附录…`、`## 台账…`、`## 过程记录` | 默认折叠 |

字段名必须用 `card-format.md` 里的原词（一句话、借的梗、为什么是现在、五维、拆梗、切入角度、风险与规避、参考内容、适合的达人类型），用全角冒号；五维的等级和依据之间用 `｜` 隔开。

## 视觉规范（写在 `assets/report.css`，仅供了解）

- **只有浅色**：暖白底 `#f5f3ee`、白色卡片，声明 `color-scheme: light`，系统开了夜间模式也不变暗
- **颜色只表达结论**：追是绿 `#1f8a5b`，等是琥珀 `#b26a00`，跳过是灰 `#5f6673`，红线是红 `#c0392b`。标题用深蓝 `#1d3557`，正文 `#1f2328`
- **字体**：系统中文无衬线（苹方、微软雅黑、思源黑体），正文 15px，行高 1.75
- **版式**：内容最宽 980px，圆角卡片、细边框、轻阴影；表格斑马纹，可横向滚动；手机上单列；打印时去掉导航和阴影
- **单文件**：样式内联，不加载任何外部字体、脚本或图片，断网也能打开
