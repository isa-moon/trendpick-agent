# 判断标准

这份文件是这个 skill 的核心。下面的规则来自真实热榜数据和借势翻车案例，不是通用常识。

## §1 先查自己：品牌与竞品的舆情状态

在挑任何梗之前，先搜整段热榜（`trend_stage.py --cluster`），四组词各跑一簇：

1. **品牌**：品牌名、子品牌、明星产品名
2. **竞品**：主要竞品
3. **品类**：品类词本身（咖啡、SUV、防晒……）。品类的健康传闻、食安事件、负面社会新闻，会让所有同品类品牌一起挨骂
4. **原料与场景**：当季主推原料和核心使用场景（例：茶饮的鲜奶、水果；越野车的沙漠、露营）

竞品的范围按用户心里的替代关系定，不按行业分类：咖啡的竞品包括连锁茶饮，SUV 的竞品包括同价位的其他动力形式。拿不准就宽一点，多跑一簇的成本很低。

品牌和竞品按下表判断状态：

| 状态 | 判断依据 | 对选题的影响 |
|---|---|---|
| 无 | 没有上榜 | 正常进行 |
| 正面/中性 | 新品、联名、活动上榜 | 可以顺势，但要避开和自家活动抢注意力 |
| **负面发酵中** | 近 7 天有相关条目上榜，且满足其一：≥ 2 条、跨 2 个平台、或有 1 条进平台前 50 | 所有**触及争议点**的梗一律跳过；整体调性降一档，不做嘲讽和自嘲；在交付物开头提醒用户，回应类内容不在本 skill 范围 |
| 零星负面 | 近 7 天只有 1 条，单平台，名次在 50 以外 | 避开争议点，整体调性不降；开头写明，并说明再上榜就按「发酵中」处理 |
| 负面已冷却 | 7 天以上没再上榜 | 可以正常进行，但仍避开争议点 |
| 竞品翻车 | 竞品负面上榜 | **不踩**：落井下石容易反噬，而且同类问题可能也落到自己身上 |
| 竞品爆火 | 竞品正面上榜 | 不跟同一个梗，避免被拿来直接比较 |

**正面和负面同时在榜**（如同一周官宣代言人、又被说销量下滑）：开头那一行两件都写。正面的可以顺势用，负面按上表的档位处理，各管各的，不要互相抵消。

> 示意（虚构，用来说明规则，不是真实数据）：某茶饮品牌正因"排队两小时、出杯慢"被骂，近 7 天仍在榜。当月一切和"等待、效率、排队"相关的梗都要避开，哪怕梗本身很火；"手慢""崩了"类自嘲更不能做。
>
> 同一个月，热榜上如果有"某某饮料致癌"的品类传闻，或者"某原料被查出违规添加"的通报，即使没点名这个品牌，任何健康暗示都会被拿来对照，涉事原料的产品这几周也不宜主推。**只查品牌名会漏掉这两类。**

海外查品牌自身用 KOX 搜品牌名和车型或产品名（`sources.md` §4），看近 30 天有没有负面视频、车主吐槽、翻车内容。出海品牌还要用国内热榜搜一次品牌名：母品牌在国内的负面（质量、融资、裁员）会被海外华人和媒体带过去。声量很小也是结论：说明这个市场的用户还不熟悉品牌，选题要先讲清楚"你是谁"，不能指望用户接住自嘲梗或圈内梗。

## §1.5 再看大环境：市场有没有在经历什么

品牌没事，市场也可能有事。战争、袭击、重大灾难、国丧、民族情绪事件期间，**整份方案的情绪底色要变**，不只是跳过相关话题。国内看热榜里有没有灾难和民族情绪类条目冲到各平台前 3；海外看年度事件页和 X 热门（`sources.md` §3）。

- 重大灾难后 7 天内不发欢快、狂欢类内容；之后也避开和灾区有关的地名、天气、场景
- 民族情绪事件（如外籍代言人辱华）期间，避开涉事人物、所属球队或品牌、所在国家的元素

- 不用战争、爆炸、"防弹 / 军规 / 装甲"类比喻，不用警报、爆破、坠落类音效和画面
- 不做"末日感""逃离"类叙事，不拿"安全感"做卖点，否则会被读成消费恐惧
- 情绪往"日常照常、家人在一起、安静、温暖"靠
- 节庆照常过，但收着做：喜庆可以，狂欢慎用

> 示意（虚构）：某地发生强震、多人遇难，连续两天各平台第 1。按 5 天上线，内容发出时已过 7 天，可以发，但不做狂欢；天气、降温、雪景类内容不出现灾区地名和相似地貌。同一周一位外籍运动员发表辱华言论、多个品牌解约：近期内容避开这个人、他的球队和所在联赛的元素。
>
> 示意（虚构）：一个海外市场正遭受跨境导弹袭击，大型活动因此延期。越野、户外品牌惯用的"硬核、征服、对抗"调性都要收，情绪往"日常照常、家人在一起"靠。

**查目标平台本身**：用户指定的平台在当地有没有被抵制、封禁、罚款，或者正处在舆论事件里（例：当地用户因为平台删内容发起抵制）。有的话，这是整份方案最重要的结论，写在开头：换平台，或者这个平台只发纯产品和服务内容。

**大环境不是只看最大的那一件事**：涉及品牌所在国、品牌门店、品牌原产地的政治和外交条目（哪怕只是一条），以及和品牌原产地相关的民族情绪，都要单独列出来。

## §2 分类与红线

先给热榜条目分类。只有前三类进入后续评估：

1. **梗**：句式、模板、动作、表情、人设（如「XX 刺客」「XX 自由」）
2. **节点**：节日、电商大促、季节变化（如万圣节、双 11、降温）
3. **文娱**：剧、综艺、游戏、赛事、明星。可以借氛围，但涉及 IP 时看黄线
4. 新闻事件、5. 政务时政、6. 灾难事故、7. 社会案件：**不进评估**

真实热榜中，4–7 类往往占大半。分类时不要因为一条热度高就放宽。

**红线**（直接进跳过清单，只写原因，不出选题）：
- 灾难、事故、伤亡、讣告
- 未定性的社会案件、违法犯罪
- 政治、外交、军事、宗教，包括政治纪念日、重大历史纪念、领导人讣告（看起来和"坚持、远行"能挂上，但商业借用就是翻车）
- 争议人物、劣迹艺人
- 和品牌自身负面舆情相关的话题（见 §1）

**黄线**（可以做，但卡片上必须写清风险和规避方法）：
- **健康与功效暗示**：食品饮料不能暗示疗效。例：饮品品牌借「X 不伤胃」类句式，容易被读成功效宣称；如果大家对这个品类的真实体验恰恰相反，评论区还会反向吐槽
- **IP 与肖像**：明星、影视、游戏截图、BGM 需要授权；只借句式，不用原素材
- **赛事排他**：大型赛事的官方标识、名称通常只限赞助商使用
- **绝对化用语**：最、第一、唯一（广告法）
- **刻板与冒犯**：性别、地域、职业。"打工人""牛马"可以用来共情，但不能由品牌来称呼消费者
- **平台语境错位**：B站梗搬到微博、TikTok 梗直译成中文，会显得生硬

海外市场额外检查：宗教与斋月等宗教时段、王室与国家象征、性别与着装、酒精、LGBT 相关表达、地区冲突。规则因国家而异，查不准时标黄并请用户找本地团队确认。

**宗教节日怎么归类**：
- 当地主流宗教的节日和时段（如海湾国家的斋月、开斋节）：按**节点**处理，带黄线规则（时段内的调性、斋戒时间、不用宗教符号做商品画面）
- 其他宗教或外来的节日（如海湾国家的万圣节、排灯节）：**黄线**。只在受众明确是对应人群、且当地对这个节日没有争议时才做；拿不准就跳过
- 宗教本身的讨论、教义、宗教人物：**红线**

## §3 生命周期：看簇的曲线，不看单条标题

**为什么必须聚类**：热榜标题几乎每天换写法。实测一个月四个平台约 1.4 万条记录，对应近 1.4 万个不同标题，单个标题极少在榜超过 2 天。所以**单个标题的阶段没有意义**，只看簇的阶段。一个梗要用一组关键词或正则聚成一簇，看它逐日出现的条数。

聚类时**检查代表条目里有没有误命中**。例：用「拿铁」会命中人名「张拿铁」，用「美式」会命中「美式复古穿搭」。

| 阶段 | 曲线特征 | 建议 |
|---|---|---|
| 🌱 萌芽 | 冒头不到 7 天，只出现在 1 个平台，或出现不超过 2 天 | 「等」：观察 2–3 天；如果品牌反应快、调性契合，可以抢跑，但要标明风险 |
| 🔥 爆发 | 近 7 天条数比前 7 天多出 30% 以上，或已跨平台 | 「追」的最佳时机，前提是上线周期能赶上 |
| 🏔 顶峰 | 近 7 天与前 7 天持平，已借势的品牌很多 | 只做反差、反向或玩法升级，不做直接套用 |
| 🍂 衰退 | 近 7 天比前 7 天明显下降，或 7 天以上没再上榜 | 默认「跳过」；只有复古或反讽的玩法例外 |

**一定要有基线**：取数时多拉前两周数据。没有基线时，所有梗都会显得是"本月第一天冒头"。

**窗口估计**：剩余窗口 = 按曲线判断还能热多久 − 品牌的制作和上线周期。剩余窗口 ≤ 0 就是「跳过」。
> 单次观察，不作为定律：一个跨 4 个平台的句式梗，从冒头到明显回落约 3 周。

**上线周期怎么算**：用户给的是"下周能上""月底前"这样的上线时间，就按**最早可上线日 − 今天**算制作周期，同时写明最晚上线日；用户什么都没说，默认 5 天，写进「我替你拍的板」。

**小样本不判阶段**：一簇总共不到 5 条，脚本会标「样本不足」。这时阶段只能结合代表条目人工判断，并在卡片上写明"样本少"。另外注意**常驻说法**：每周都有几条、一直没断、也没有明显的峰（如"X 的含金量"），不是热梗，没有借势红利。脚本遇到这种曲线会打 ⚠ 提示，是不是常驻由你看代表条目决定。

**节点不看曲线**：节日、大促、节气的日期是已知的，按日期倒推排期，不要用脚本给的阶段（大促前后的条目起落反映的是平台投放节奏，不是热度寿命）。

**饱和度**：搜一下「品牌名或品类 + 梗」，看已经有多少品牌和蓝 V 账号做过（`sources.md` §4）。已经扎堆的，即使曲线还在涨，也按顶峰处理。

没有饱和度检索工具时，先看热榜本身：簇里有没有品牌、平台活动、电商大促的条目（如「双 11 拿到 X」「某平台大会抢到 X」），有就说明已经被用上了。这一维写「中（未验证）」，**不拦推荐**（「没有出处不出」管的是梗、数据和参考案例，不管这一维），但卡片上要写一步上线前自查：在抖音或小红书搜「梗 + 品类」，看前 20 条里有几个品牌号，超过 5 个就按顶峰处理。

## §4 五维关联度：每一维都要写依据

不打 1–10 分。每一维给「强 / 中 / 弱 / 冲突」，后面跟一句依据（数据、链接或推理）：

| 维度 | 问题 | 依据举例 |
|---|---|---|
| 受众重合 | 这个梗主要在谁中间流行，和品牌受众是同一群人吗 | 主要出现在哪个平台、代表条目的语境 |
| 产品接得住 | 品牌有没有真实的卖点或场景可以挂上去，而不是硬凑 | 具体到某个产品、某个使用场景 |
| 调性不冲突 | 梗的气质和品牌人设是否冲突，是否触及 §1 的争议点 | 梗是丧、是爽、是嘲讽、是温情 |
| 窗口够 | 剩余窗口能否覆盖制作和上线周期 | §3 的曲线与窗口估计 |
| 没被做烂 | 已经借势的品牌多不多 | §3 饱和度检索结果 |

## §5 决策

- 任意一维为「冲突」→ **跳过**
- 「窗口够」为弱 → **等**（节点未到）或 **跳过**（梗已衰退、节点在上线前结束）
- 窗口只在最早上线日成立（再晚两三天就过峰）→ 记「强（有条件）」，卡片标题写出上线期限，并写明晚于哪天就改判跳过
- 「产品接得住」为弱、品牌也没有可讲的机制或合作 → **跳过**（等不来信号的，不要放进「等」）
- 至少 3 维为强、且没有弱项 → **追**
- 其余 → **等**，写清楚要等什么信号（例："如果 3 天内出现在第二个平台就追"）

**节点的「没被做烂」**：节点年年有人做，这一维对节点几乎总是「中」，不算弱项，前提是切入角度能和常见做法拉开差异（在卡片上写出常见做法是什么）。被电商、平台投放占满的节点（如大促）算「弱」：只有品牌自己有机制可讲时，才以服务型内容进「等」，否则跳过。

宁缺毋滥。一个月里真正值得一个品牌追的梗，通常只有个位数；如果推荐超过 5 条，回头检查是不是放宽了标准。

## §6 切入点：借结构和情绪，不借梗源

把梗拆成三层：
- **结构**：句式、模板、动作、画面构图 → 可以借
- **情绪**：爽、丧、反差、治愈、共鸣 → 可以借
- **梗源**：具体的人、事件、作品片段 → 默认不碰（肖像、版权、当事人意愿都是风险）

每个「追」给 2–3 个角度，角度之间要有实质差异（例如共鸣型、反差型、玩法型、服务型），不要同一个点子换皮。每个角度写：

- 一句话说明（借了梗的什么 × 挂在品牌的什么上）
- 3 秒钩子（开头一句或第一个画面）
- 品牌露出点
- 这个角度特有的风险
