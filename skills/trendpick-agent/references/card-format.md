# 交付物格式

用户最先读的是开头几行，最后才看细节。顺序固定。

整份存成 Markdown 文件：`<台账目录>/<品牌>-<YYYY-MM-DD>-选题.md`（同一天跑第二次，加 `-2`）。对话里只给开头几行、推荐卡标题和文件路径，不要把全文再贴一遍。

## 1. 开头几行

```
数据：<平台>热榜 <起>–<止>（截至 <日期>）+ 前两周基线；海外检索于 <日期>
品牌自身：<品牌、竞品、品类、原料的状态，一句话结论 + 关键证据链接>
大环境：<灾难、冲突、民族情绪事件；没有就写「无」>
结论：推荐追 N 条｜观察 M 条｜建议跳过 K 条（其中红线 X 条）
```

K 和 X 只数跳过表里列出来的条目。跳过表只列**用户可能想追**的：和品牌、品类直接相关的，或者热度高到会有人问"这个能不能借"的。热榜上其余的灾难、时政条目不用逐条列，在数据说明里写一句"其余新闻、时政类按红线排除"即可。

## 2. 推荐卡（追）

```markdown
### 【追】<选题名，一句话>
**借的梗**：<梗名> ｜ <阶段 emoji + 阶段> ｜ 剩余窗口约 <N> 天（理由：<曲线依据>）
**为什么是现在**：<首次出现日期、峰值、跨平台情况、近 7 天 vs 前 7 天>，代表条目：<平台#名次 日期 标题>（<链接>）
**五维**：
- 受众重合：强｜<依据>
- 产品接得住：强｜<具体产品或场景>
- 调性不冲突：中｜<依据>
- 窗口够：强｜<剩余窗口 vs 上线周期>
- 没被做烂：强｜<饱和度检索结果>
**拆梗**：结构 <可借> ｜ 情绪 <可借> ｜ 梗源 <不碰的部分>
**切入角度**：
1. <角度名>：<一句话>。钩子：<3 秒开头>。露出：<品牌点>。风险：<该角度特有>
2. ...
**风险与规避**：<🟡 黄线项 + 怎么规避>
**参考内容**：<2–3 条真实链接，标平台和日期；没有就写「未找到，建议先发一条测试」>
**适合的达人类型**：<类型；如需具体名单可接达人工具>
```

**海外版**的差异：海外没有平台名次和逐日曲线。
- 开头「数据」一行写：<来源列表>，检索于 <日期>，没有逐日曲线，阶段是粗判
- 国内的节点（节气、节日）热榜上常常还是 0 条，这是正常的。「为什么是现在」写节点日期和来源，加上相关的季节或天气簇的曲线（如「降温」簇），不硬凑「平台#名次」
- 「为什么是现在」写：节点日期和官方来源；或者 KOX 真命中的发布分布（W3→W0）和头部视频链接；不写「平台#名次」「近 7 天 vs 前 7 天」
- KOX 输出原表放文末附录，卡片里只引用关键数字，误命中在附录里标出

## 3. 观察（等）

每条一行：梗、当前阶段、在等什么信号、预计什么时候再看。

## 4. 建议跳过

用表格。这一节要写得和推荐卡一样认真：用户最容易自己想追的，往往就在这里。

| 条目 | 为什么看起来能追 | 为什么不追 | 类型 |
|---|---|---|---|
| 「X 不伤胃」句式梗 | 本月最火的句式梗之一，和饮品场景相关 | 已进入衰退期；饮品说"不伤胃"有功效暗示风险 | 时机 + 黄线 |
| 某灾难事件 | 热度第一 | 红线 | 红线 |

## 5. 我替你拍的板

用户没有回答、由你按默认值决定的事项，每条写清默认值和改了会影响什么。

## 6. 数据说明

用了哪些数据源、哪些没用上及原因、数据的局限（例如"海外没有逐日曲线，阶段为粗判"）。

---

## 写作要求

- 用户是营销从业者，用行业通用说法，不解释"什么是借势"
- 数字都带来源；推断和事实分开写（推断前加"判断："）
- 一条选题卡控制在一屏以内；长的证据放到文末附录
