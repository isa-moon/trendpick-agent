# 评测

两个真实需求，各跑两次：不装 skill（基线）和装 skill（盲测）。按 [rubric.md](rubric.md) 的 12 项打分，通过记 1、部分通过记 0.5。

- **基线**：同一需求、同样的数据工具（热榜 MCP、WebFetch、KOX），不装 skill
- **盲测**：另起一个 Agent，只给它 skill 和需求，不给参考答案，不让它读 `cases/`；跑完后要求它列出 skill 里不清楚、矛盾或只能靠猜的地方
- 两次运行都在 2026-10-28，数据截至 10-27 / 10-28

| 文件 | 内容 |
|---|---|
| [baseline/starbucks-baseline.md](baseline/starbucks-baseline.md) | 星巴克，不装 skill |
| [with-skill/starbucks-with-skill.md](with-skill/starbucks-with-skill.md) | 星巴克，装 skill（盲测），文末附过程记录和困惑点 |
| [baseline/rox-baseline.md](baseline/rox-baseline.md) | 极石 ROX 中东，不装 skill |
| [with-skill/rox-with-skill.md](with-skill/rox-with-skill.md) | 极石 ROX 中东，装 skill（盲测），文末附过程记录和困惑点 |
| [trigger_cases.json](trigger_cases.json) | 触发测试：10 条应触发、7 条不应触发 |

## 结果

| | 星巴克 基线 | 星巴克 装 skill | ROX 基线 | ROX 装 skill |
|---|---|---|---|---|
| 得分 | 3 / 12 | 12 / 12 | 5.5 / 11 | 10.5 / 11 |
| 结论 | 追 5，另附 3 条不建议 | 追 1｜等 3｜跳过 16 | 追 5（含 iPhone 18、利雅得季），无跳过表 | 追 2｜等 5｜跳过 15 |
| 第一推荐 | 「这杯喝了不烧心」（已过峰 + 功效暗示） | 立冬 × 降温（节点，按日期倒推） | 露营季开季 | UAE 冬季露营季 × 对外放电 |
| 来不及的节点 | 推荐了万圣节（3 天后） | 无 | 无 | 无 |
| 参考案例 | 4 处"基于训练知识，请核实" | 全部带链接 | 带链接 | 全部带链接，打不开的标"需复核" |
| 默认值 | 没写 | 单列 | 没写 | 单列 7 项 |

ROX 的第 6 项（衰退梗不追）不适用，满分按 11 计；扣的 0.5 在第 4 项，海外没有逐日曲线，阶段只能按节点日期和 KOX 发布分布粗判。

第 12 项（写入台账）：按测试规则，盲测 Agent 不往用户目录写文件，台账内容写在交付物文末，按"内容完整"计通过。

## 要说清楚的

- **基线并不弱**。不装 skill 的 AI 找热点、写创意都很强：星巴克基线自己找到了骨质疏松传闻和硫磺桂花，ROX 基线找到了胡塞袭击、写出了"脱困小课"。差距在判断：时机、窗口、跳过、出处
- **星巴克盲测有污染**。当时 judgment.md 的举例用的就是星巴克本案，盲测 Agent 自己指出了这一点（见其文末第 1 条）。所以 12 / 12 要打折看。但它也找到了我们自己那版漏掉的东西：两条涉政的星巴克海外条目、涉日民族情绪、「赛车星冰乐」误命中、「X 的含金量」是常驻说法
- **ROX 盲测用的是清理后的 skill**（举例全部换成虚构示意）。它独立发现了沙特的 TikTok 抵制，这是整份方案最重要的结论，我们自己写 skill 时跑的那版（`cases/rox/`）漏了
- 两个案例都没有做社媒饱和度检索（付费工具），"没被做烂"一维偏乐观

## 盲测之后改了什么

**judgment.md**
- 所有星巴克、沙特的举例换成虚构示意
- 新增"查目标平台本身"：平台在当地有抵制、封禁、争议时写在交付物最前面，换平台或只发产品和服务内容
- 竞品范围按用户心里的替代关系定（咖啡 vs 连锁茶饮）；出海品牌也查母品牌的国内舆情
- 宗教节日归类：当地主流宗教的节日是节点（按黄线规则做），其他宗教或外来节日是黄线，拿不准就跳过；宗教讨论是红线
- 单个标题不判阶段，只看簇；节点按日期排期，不看曲线；总条数 < 5 记"样本不足"；"上线周期 = 最早上线日 − 今天"，默认 5 天
- 决策表：产品接得住为弱、品牌又没有机制 → 跳过（之前只能给"等"）；节点的"没被做烂"通常是中，被电商做烂的节点为弱

**sources.md / card-format.md**
- 海外找梗的路径：Know Your Meme 等全球梗 → KOX 在当地验证 → 当地盘点和 X 标签；找不到梗时只出节点和季节，并在结论里写明，不算失败
- 品牌事实可以只有一个来源，标"需品牌确认"
- 阿语内容系统性低估，给出替代渠道（本地团队、X 阿语搜索、Snapchat）
- 海外版卡片模板；KOX 原表放附录，卡片只引关键数字
- K、X 的计数只算"用户可能想追"的条目，其余红线新闻在数据说明里一行带过

**scripts/trend_stage.py**
- 概览和 `--grep` 不再给单个标题判阶段
- 新增 `--show`（代表条目条数）、`--middle`（找"X 在中间"的句式）
- 簇输出逐周曲线；连续 5 周以上每周都有、没有明显峰值的，提示"可能是常驻说法"

**scripts/video_pulse.py**
- `--must` 从子串匹配改成按词边界匹配（`tank` 不再命中 `thank`），`#标签` 只匹配标签
- 分桶按数据跨度自动选周或 4 周，不再丢掉 28 天以上的条目，365 天检索也能看出分布
- 删掉残留的默认品牌词；提示里说明 KOX 按作者去重、品牌号只按作者名识别
- 同形词（hatta 既是地名也是头巾的转写）脚本分不出来，文档要求看头部视频人工剔除

改完后用同一份数据回归：星巴克 9 个簇的阶段（「不烧心」衰退、「可可」顶峰、「冷空气」爆发、「万圣」样本不足等）和改之前的人工判断一致。
