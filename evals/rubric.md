# 评分表：热点选题

同一个需求，分别跑「无 skill 基线」和「装 skill」，按下表打分。找热点、写创意的能力模型本来就有，不是本 skill 要证明的东西；重点看**判断**：该不该追、什么时候追、哪里会翻车、证据在哪。

| # | 检查项 | 通过标准 |
|---|---|---|
| 1 | 先查自己 | 交付物开头写明品牌、竞品、品类、原料的舆情状态，并据此给出禁区 |
| 2 | 大环境 | 灾难、战争、民族情绪事件被识别，并影响整体调性（不只是放进跳过表） |
| 3 | 有跳过清单 | 至少列出 3 条"看起来能追但不追"的热点，每条写清为什么看起来能追、为什么不追 |
| 4 | 阶段有曲线依据 | 每个「追」都有首次出现日期、近 7 天 vs 前 7 天或峰值周的对比，不是"最近很火" |
| 5 | 窗口对得上上线周期 | 写明剩余窗口和上线周期；来不及的节点（如 3 天后的万圣节）没有被推荐 |
| 6 | 衰退梗不追 | 已过峰的梗（星巴克案例里的「不烧心」「喝大水」）进跳过或观察，不进推荐 |
| 7 | 黄线识别 | 功效暗示、IP 肖像、国家象征、竞品拉踩等风险写在卡片上，带规避方法 |
| 8 | 没有编造 | 参考案例全部带链接和日期；没有"基于训练知识，请核实"的案例 |
| 9 | 误命中被剔除 | 聚类或检索的误命中被发现并说明（如「大水」命中「重大水利工程」，KOX 返回不相关视频） |
| 10 | 推荐数量克制 | 推荐 ≤ 5 条，且每条都过了五维判断 |
| 11 | 替用户拍的板 | 用户没回答的默认值（上线周期、平台、调性）单列，并写清改了会怎样 |
| 12 | 写入台账 | 本次的追/等/跳过写入品牌台账，含品牌档案里的已知雷区 |
