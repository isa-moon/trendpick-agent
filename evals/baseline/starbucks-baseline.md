## 选题 1：「这杯喝了不烧心」——借本月头号热梗"不烧心"

**热点依据**
- "不烧心"是本月覆盖最广、最长寿的网络梗：抖音、B站、微博、知乎四个平台都有，10 月里除 25 日外每天都有相关词条上榜，10-09 当天就有 9 条。
- 代表词条：抖音"全员进入不烧心时代"(843.2)、"全网进入不烧心时代"(773)、"这顿饭已严肃品鉴不烧心"(1054.4)、"秋天这样穿不烧心"(919.2)、"今年双11买啥不烧心"(766.5)、"不烧心可可妆"(765.7)；B站"吃了不烧心是什么梗【梗指南】"(208.9)、"这奶茶喝了不烧心"(79.1)；知乎"如何评价最近爆火的「不烧心」梗？"(222)。
- 用法：形容一样东西"舒服、踏实、不添堵、不踩雷"，句式是"××××不烧心"。
- 生命周期：10-09 前后到顶，月底仍有新词条（10-27 抖音"想要秋天不烧心就去山里野"1051.1），正从顶峰滑向长尾。**窗口期大概还剩 1~2 周，要做就得快。**

**具体做法**
- 主题："咖啡喝多了是真会烧心——所以给你一份『不烧心』喝法"。拿"烧心"字面意思（胃灼热）自嘲一下，接梗显得自然，也不会被说硬蹭。
- 形式：
  1. 小红书 / 抖音图文卡片「星巴克不烧心点单指南」：低因 / 半糖 / 换燕麦奶 / 空腹别点浓缩，配一款当季在售饮品加一款烘焙做"不烧心搭子"。（具体 SKU 由菜单组按 10 月实际在售替换，不要写功效宣称。）
  2. 门店手写板 / 杯套贴纸："今天这杯，不烧心。"
  3. 微博互动话题 #你的不烧心时刻#：征集"今天哪件小事让你不烧心"，选出的评论做成杯套文案。
- 发布建议：本周内（10-29~11-02）上线，赶上梗的长尾。

**风险**：别说"咖啡不伤胃 / 养胃"这类功效话；评论区的"消费入座"吐槽要提前备好统一回复口径。

**参考案例**
- 数据内：B站 UP 主"这奶茶喝了不烧心"(10-12，79.1)，可见饮品已经天然被纳入这个梗的使用场景。
- 历史（基于我的训练知识，请核实）：肯德基"疯狂星期四 / v我50"——品牌把用户自发的梗收编成固定栏目，长期运营；瑞幸 2020 年接"秋天的第一杯奶茶"梗、做成限定产品的思路也类似。

## 选题 2：「可可系的秋天，从一杯开始」——借秋冬"可可系"审美 + 秋日色彩

**热点依据**
- 本月抖音"可可系"相关词条持续上榜：绝美旗袍可可妆(937)、秋天最有腔调的流金可可妆(763.1)、维密大秀上的可可系穿搭(769)、可可系穿搭狠狠击中我的审美(768.1)、可可系红毯造型好权威(767)、热巴红毯月冕蝶神可可妆(10-26，764.8)、山野可可系穿搭上新人了(764.1)。
- 秋冬穿搭和秋景也是长期热门：古早感美式复古秋冬穿搭(1212.4)、松弛感秋日穿搭合集(1046.4)、枫叶一红就知道该出片了(781.4)、秋日收藏小赛(10-23，970.5)。
- 可可、焦糖、咖啡本来就是"可可系"色卡里的颜色，**这是品牌色和流行色天然撞上的一个点**。

**具体做法**
- 主题："今年秋天的流行色，星巴克杯里一直都有"。
- 形式：
  1. 小红书色卡帖「可可系配色 × 星巴克秋冬饮品」：拿 4~6 杯当季饮品（拿铁、焦糖、摩卡、可可类）的液体颜色对照穿搭色卡，像"浅可可 = 燕麦拿铁 / 流金可可 = 焦糖玛奇朵 / 深可可 = 摩卡"这样对应起来。
  2. 抖音 / 小红书 KOC 合作"可可系秋日 OOTD + 手里一杯"街拍。挑穿搭和美妆博主，不要只找咖啡博主。
  3. 门店 / 线上发起 #可可系杯搭# 拍照征集：杯子入镜、穿搭同色系，参加的人送下次升杯券。
- 发布建议：10 月底到立冬（11-07）前后，衔接秋冬上新。

**风险**：选饮品时避开桂花原料（硫磺桂花事件余波）；色卡里的颜色要和实拍杯子对得上，别过度调色，否则会被说"照骗"。

**参考案例**
- 数据内：抖音"不烧心可可妆"(10-19)，说明可可系和"不烧心"已经有人叠着用，选题 1 和 2 可以联动。
- 历史（基于我的训练知识，请核实）：2024 年秋"美拉德穿搭"走红时，多家茶饮咖啡品牌推出"美拉德色"秋季饮品或营销，做法就是"流行色 = 饮品色"。

## 选题 3：「喝大水时代，你的大杯是哪一杯？」——借"喝大水 / 纯过日子"极简生活梗 + 双11

**热点依据**

- 双11：10 月中旬全面开启（抖音"抖音商城双11超级补贴来啦"1223.6；微博"天猫双11和王安宇打开淘宝出发"628），讨论一直持续到月底。

**具体做法**
- 主题："喝大水时代，给自己挑一只大杯"，主推星巴克**大容量随行杯 / 保温杯 / 吸管杯**，再加上咖啡豆、胶囊这类"纯过日子人的在家咖啡"。
- 形式：
  1. 天猫 / 抖音旗舰店双11内容「纯过日子人的星巴克双11清单」：一只大杯（喝大水）+ 一袋豆子（在家一杯）+ 一张星礼卡（偶尔犒劳自己）。

  3. 门店小动作：自带杯减价 / 加热水，配文"喝大水，我们支持"。这句同时是一句软性善意，能替"消费入座"补一点口碑。

**风险**：别把"喝大水"包装成健康建议（10-08 已有"三甲医生称喝大水不等于科学饮水"30、"医生回应年轻人开始喝大水"）；只当生活态度梗用，不碰医学。

**参考案例**

- 历史（基于我的训练知识，请核实）：星巴克中国 2019 年"猫爪杯"，周边 / 杯子本身就能成为社交货币和抢购话题；Stanley 大容量保温杯在海外靠"随身大杯"生活方式内容走红。

## 选题 4：「这届万圣节有点鬼主意」——10.31 万圣节门店 / 杯子轻互动

**热点依据**

- 本月万圣节话题的风格是"萌系、轻 cos、妆发"，不是恐怖。另外冰雪大世界官宣联名迪士尼(1209.9)，说明大众对 IP / 萌系联名反应不错。

**具体做法**
- 主题："今天来星巴克，带点鬼主意"。
- 形式：
  1. 10-31 当天门店轻互动：穿 cos / 戴发箍 / 画万圣妆到店，凭口令"有点鬼主意"享一项小福利（升杯、加料或贴纸）。伙伴可以戴统一的万圣发箍，在杯身手绘小南瓜、小幽灵。

- 发布建议：**时间最紧**（距 10-31 只剩 3 天），先用门店物料和社媒预热帖，10-31 当天集中做 UGC 转发。

**风险**：别做惊悚血腥的画面；"消费入座"期间，cos 到店互动要明确说"带走也算"，免得变成"不消费不让进"的新槽点。门店执行要给伙伴减负（对应知乎"会增加一线员工负担吗？"的讨论）。

**参考案例**

**参考案例**
