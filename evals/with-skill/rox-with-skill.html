skill 里不清楚、矛盾或只能靠猜的地方：

  1. 海外怎么找「梗」基本没有可执行的路径。sources.md §3 列的 TikTok Creative Center 要登录；KOX 只能按关键词搜，不能浏览当地热门；trends24 是 X，不是 TikTok。最后我用 Know Your Meme 找全球梗，再用 KOX 验证当地有没有信号，3 个全是 0。结果整份方案只有节点、没有梗。skill 说了「节点比梗更可靠」，但没有说找不到梗时这样算不算完成、怎么写，也没说该不该先用全球梗去当地验证。建议补一句明确兜底，比如「海外找不到 2 源验证的梗时，只出节点和季节，并在结论里写明」
  2. 「平台本身在出事」没有被覆盖。§1.5 讲的是灾难、战争、民族情绪，§1 讲的是品牌和竞品，但这次用户指定的平台（沙特 TikTok）正在被民族情绪抵制。这一条是我靠自己判断加上去的，而且是这份交付物里最重要的结论。建议 §1.5 加一条「检查目标平台在当地有没有抵制、封禁、舆论事件」

脚本（video_pulse.py）的问题：

  1. --must 是子串匹配，误命中很多：「hatta」命中「hattaweeqal」（hatta 在阿语里是头巾）；「cat」命中「cat eye」和猫蛋糕；「winter」命中美妆的「winter kissed」；「nationalday」把沙特国庆的视频算进了 UAE 国庆；「tank」会命中「thank」。建议支持以 # 开头的标签精确匹配，或者按词边界匹配
  2. 分桶有 bug：min((asof - d).days // 7, 4) 把 28 天以上的条目放进第 4 桶，但输出只打印 W3→W0。所以 --days 30 时最后 2 天的条目会悄悄丢掉；--days 365 时分布全是 0 0 0 0，但命中是 20/20（eidaletihad_365d），很容易误读成「近期没人发」。另外 create_at 晚于 asof 时 days 为负、落进第 -1 桶，也不会打印
  3. 默认 --brand-words 里写死了「hisense」，像是上一个案例的残留。品牌号只按作者名判断，Nesto、TobySouq 这种零售账号认不出来，所以品牌号占比偏低
  4. 话题名取自文件名，--must 的键要和文件名完全一致，例如 uae_national_day。文档里没有提醒，一不小心就会退回到用查询词本身匹配
  5. KOX 返回的参数里有 unique_author: 1（每个作者去重），所以「命中/返回」统计的是作者数，不是视频数。脚本和 skill 都没有说明
  6. 阿语检索返回 0 时，脚本给的提示是对的，但沙特本地内容因此系统性缺失，skill 没有给替代渠道（比如 Snapchat 或 X 的阿语搜索）
